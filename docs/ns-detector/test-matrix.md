# 验证矩阵与发布门槛

本轮增强范围与逐项门槛见[阶段性需求](requirements.md)。本文列出必须验证的范围，不声称表中的真机项目已经完成。每个发布候选应记录源码提交、APK SHA-256、签名指纹、设备型号、SoC、Android/API、安全补丁、内核、ABI、操作步骤和原始结果。未经实测不能公布“100% 检出”“零误报”或达到性能目标。

已发布候选版的实际结果见 [1.0.0 验证记录](validation-1.0.0.md)。

## 自动验证

| 层次 | 要验证的内容 | 能得出的结论 |
| --- | --- | --- |
| 仓库守卫 | 原有 18 检测器、18 native 单元、10 进程/Provider 入口保留；模块边界、证据文档、JNI 契约、反射、文本协议、源码长度 | 静态工程约束满足；不能证明探针在所有设备正确。 |
| JVM 单元测试 | reducer、mapper、解析器、网络信息状态、历史与脱敏规则；新增应用签名/调试观察、类型化筛选和调度回归 | 给定输入得到预期结果。 |
| APK / AAR 构建 | 四个 ABI 的编译、资源、混淆与 SDK 消费示例 | 工具链和依赖可构建，产物能链接。 |
| lint / API / 依赖检查 | Android 用法、公共接口兼容、显式依赖 | 发现相应的静态问题。 |
| Android 模拟器 | 安装、冷启动、同意/拒绝选项、扫描界面、截图和崩溃日志 | 当前系统镜像下基本运行；不代表真机安全硬件与内核验证。 |

实际通过状态以 [Actions](https://github.com/withite/ns-detector/actions) 中对应提交为准。正式签名产物另需校验 `apksigner`、证书指纹、APK SHA-256、包名和版本码。

## 真机矩阵：尚待执行

| 场景 | 最低覆盖 | 重点检查 |
| --- | --- | --- |
| 原厂锁定 | Android 10 至当前稳定版，多厂商与多 SoC arm64 | 启动链、权限拒绝、SELinux、无异常环境的误报。 |
| 解锁但未 Root | 独立于 Root 的样本 | Bootloader 观察不能被误写成 Root 结论。 |
| Root | 已知配置的 Magisk、KernelSU、APatch 样本 | 分类检出、隐藏后的观察限制、单项失败不影响整轮。 |
| 受控 Hook/注入 | LSPosed、Zygisk、Frida 等明确版本的实验样本 | Java/native、多进程证据及误报。 |
| 定制 ROM / 无 GMS | 合法自定义系统、离线模式 | 组件缺失、包可见性和证明不可用不能显示通过。 |
| 企业与普通网络 | 企业 VPN、用户代理、Private DNS、工作资料、飞行模式 | 信息性显示，不形成无依据的高危结论。 |
| 虚拟环境与多开 | Android 模拟器、容器、OEM 工作资料/双开 | 区分特征观察、合法容器、受限接口与不支持架构。 |
| 硬件证明 | 有/无 StrongBox、TEE、不同 KeyMint/Keymaster 代际 | 设备侧解析与独立可信验证的边界、吊销快照过期/离线状态。 |
| 多进程/原生入口 | NativeActivity、app zygote preload、隔离服务 | 独立应用 ID 后启动正常，服务不串到上游/Debug 实例。 |
| 安装与升级 | Debug/Release 共存、同签名升级、错误签名安装 | 历史保存、版本递增、升级与卸载提示。 |

## 产品与数据验收

- 扫描取消、超时、部分失败、拒绝授权、旋转与进后台后，界面保留准确执行状态；进度依据实际 ready 模块，筛选不改变全局扫描与统计。
- 历史存储可回看，连续两次扫描能区分新增、消失和变化；中断扫描不假装完成，清除后旧协程/旧界面实例不得恢复记录。
- 导出的默认脱敏报告覆盖网络地址、设备标识、敏感路径与证明材料；畸形输入和异常文本有回归用例。文档选择器旋转/恢复后保持同一冻结报告，取消时清理临时文件。
- 清除/卸载会移除私有历史；分享副本仍由用户管理。深浅色、大字体、屏幕阅读器和窄屏可读。
- 四 ABI 原生库，以及具备条件时的 16KB 页面设备安装与启动；缺少实际环境时记录缺口。
- 应用完整性新增项：精确包名/签名命中、无 pin、错误 pin、debug/testOnly、多签名、签名轮换、PM/调试 API 失败和 TracerPid 畸形/拒读均有明确语义；命中不能展示为整机可信。
- 进程沙箱：普通/系统/多用户宿主、采样期间身份变化、合法 wakelock 能力位、缺失/异常 proc 字段与未知 Seccomp 模式；观察只代表同一采样线程，不推广到其他线程。
- CA 存储：Android 10 至当前版本、当前用户与工作资料、合法用户 CA 安装/移除、提供程序缺失、目录不可见与枚举截断；零计数不推断底层存储为空，不推断实际 TLS 信任。
- 更新前核对候选包名及当前签名集合；APK 解析、持久化锁等待与报告渲染不在主线程阻塞。

## 性能与准确率

快速扫描性能初始目标为中端 arm64 真机 p95 ≤ 5 秒；硬件证明、实验性探针和联网步骤单独计时。该数值是待验证目标，当前没有基准测试数据。基准需注明冷/热启动、样本量、温度、后台负载、权限和启用模块。

准确率按检测类别记录已知阳性检出、正常场景误报、无法观察比例和失败比例；不能将“无法判断”算作正确阴性。报告样本数量和条件，不以一个总体百分比掩盖类别与设备差异。

`motion.yml` 提供动画开启时的同模拟器配对绘制证据：两版清装、默认水印、相同输入，采集空闲、滚动和重启扫描窗口。FRAMESTATS 只包含有限最近帧，系统 jank 与按截止时间计算的延迟单独记录；固定先旧后新的顺序、主机负载、启动编译及新增检测工作会影响结果。模拟器结果不替代真机刷新率、大字体、无障碍和热状态验证。

## 当前不包含的发布保证

当前交付不包含 Google Play 上架批准、Play Integrity 后端、独立可信 Key Attestation 服务端、未公开 Root/Hook 的通用识别，或已完成的多厂商真机认证。正式公开稳定版需补齐上述适用的真机验收记录，并将未满足项作为已知限制公开。
