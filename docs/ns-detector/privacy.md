# 隐私与数据处理

## 设备端检测

核心扫描在设备端执行，无需注册账户或 Root。检测内容可能包括系统属性、启动状态、应用可见性、进程和内存迹象、证书与 KeyStore 证明、本应用默认网络及代理配置。这些是诊断环境所需的观察，不能覆盖 Android 沙箱之外的所有状态。

网络模块不保留代理端点、PAC 地址或 Private DNS 主机名，也不抓取 PAC 脚本。本应用完整性模块仅读取当前宿主的公开签名信息、debuggable / testOnly 标记、Java 调试状态及有界的 `/proc/self/status` 中 `TracerPid` 字段；不保留原始 status 文件，不读取其他进程，不访问私钥，也不向服务端上传证书或调试状态。签名指纹与内置策略的比较属于本地诊断，不能独立证明应用或设备可信。

网络模块还统计当前用户或工作资料可见的 AndroidCAStore 条目，只保留用户、系统与未知分类数量，不保留证书内容、别名、主题、签发者或指纹；数量不代表应用实际的 TLS 信任配置。进程沙箱模块最多读取 64 KiB 的 `/proc/thread-self/status`，比较同一采样线程的 UID 视图并观察已授权能力和 Seccomp 模式；报告与历史不保存该原始快照、UID 或线程 ID，不读取其他进程或尝试提权。

普通应用仍受权限、包可见性、SELinux、命名空间和厂商实现限制。JNI 或直接系统调用不会自动绕过这些限制。扫描失败、不支持、无法访问的结果需与“未发现”区分。

## 何时联网

- 核心扫描不上传报告，也不依赖诊断后端。
- 冷启动不自动检查 GitHub 更新。用户在设置中显式检查更新、确认下载或打开仓库链接时会访问 GitHub。
- TEE 吊销检查包含本地快照；用户允许在线刷新后，会下载 Google 发布的吊销信息。下载本身不等于将本地证明提交给独立验证服务。
- 第三方 GitHub 加速默认关闭。启用后，相关更新请求/下载会经过设置中标明的第三方代理；代理能够观察请求路径和网络地址。
- 外部站点按照其自身隐私政策处理连接元数据；GitHub Actions 的构建日志和产物公开范围取决于仓库可见性。

NS Detector 没有把 Google Play Integrity 验证服务端或独立 Key Attestation 可信验证服务包含在当前交付中。若未来增加，需要另行说明网络数据与服务端校验流程。

## 本地历史与导出

扫描历史保存在应用私有 SharedPreferences（`ns_detector_scan_history`）中，最多保留 20 次已完成扫描；取消或未完成的扫描不保存。历史仅保存完成时间、耗时、检测器稳定 ID、类型化状态和最多 240 字的脱敏摘要，不保存原始报告、证据明细或设备身份。页面的“本地扫描历史 / 清除”可以删除历史。Debug 与正式版因应用 ID 不同，分别存储。应用关闭 Android 自动备份，并在 cloud-backup / device-transfer 规则中排除私有数据；卸载或清除应用数据会移除本地记录。用户主动保存到其他位置的报告或分享副本不受应用卸载影响。

TXT 与 `schemaVersion=1` JSON 报告均默认脱敏，没有原始报告导出开关。规则处理邮箱、IPv4/IPv6、MAC、用户私有/存储路径、URL 认证信息、Bearer/Basic、JWT，以及具名 serial、IMEI、Android ID、token、password 等敏感字段，以减少设备标识、地址和凭据的暴露。未知格式仍可能保留。脱敏并不保证绝对匿名：设备型号、Android 版本、检测组合、时间和错误细节仍可能帮助识别设备。公开提交 Issue 前请人工检查，必要时删除仍可识别个人、网络或企业环境的信息。不得把默认脱敏理解为自动批准公开原始日志或证书。

等待系统文件选择器保存期间，脱敏后的导出内容临时保存在应用私有、不参与备份的目录。保存完成、失败或取消后清理；意外退出遗留的临时文件会在后续导出流程中按 24 小时有效期清理。模块搜索与筛选不会从完整报告或历史中删去被隐藏的模块。

比较依据检测器 ID 与类型化状态，显示新增 Warning/Danger、状态变化和覆盖移除；只有已有发现变为 All Clear 才作为解除。模块消失或失去可见性不算解除，文案差异不算证据变化。结果仍可能受到权限、网络切换、系统升级和探针可用性影响；变化本身不等于新发生的攻击。

## 权限

| 权限/能力 | 用途与边界 |
| --- | --- |
| 包可见性 | 支持可疑应用与 Root 管理器的证据观察；拒绝或受系统限制会降低覆盖。 |
| 网络状态 | 读取本应用默认网络、VPN transport、代理与 Private DNS 信息；不嗅探其他应用流量。 |
| Internet | 用户授权的吊销数据刷新、显式更新检查/下载等。 |
| 通知/Live Update | 展示扫描进度与状态；拒绝后仍可在应用内查看。 |
| 生物识别能力 | 部分 KeyStore/硬件能力相关路径；设备支持程度因厂商不同。 |

仅观察到 VPN、代理、Private DNS、用户安装证书或开发者选项，不能据此断言设备已被入侵。网络模块不进行主动探测或上传，也不改变设备网络设置。
